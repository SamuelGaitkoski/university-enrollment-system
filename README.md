# Sistema de Matrículas

Sistema de atendimento e matrículas de uma universidade, desenvolvido como Desafio da disciplina **Programação Front-end** (Unisinos).

- **Visão institucional (secretaria):** cadastra disciplinas, professores e alunos e monta a grade de ofertas de turmas.
- **Visão do aluno:** consulta as ofertas e se matricula nas turmas.

**Tecnologias:** React + Vite, React Router, Bootstrap/React-Bootstrap, Node + Express (persistência em arquivo JSON).

## Como rodar

Pré-requisito: Node.js 20.19 ou superior.

```bash
npm run install:all   # instala raiz, backend e frontend
npm run dev           # back em http://localhost:3001 e front em http://localhost:5173
```
